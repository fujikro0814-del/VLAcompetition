- 復帰の定義: 誘発が成立した試行のうち、`t_success ≤ 30` で成功したもの（成功の側は `≤`、成立の側は `<`。掲示板 0155 の 1）。
- 層別の検定の理由: 帰無仮説の下では、どの層でも食い違った組は半々になる。だから層の合計 b も、b＋c を条件にすると二項（確率 0.5）に従う（条件つきの正確検定）。層ごとの b_s・c_s も表に並べる。
- **H2 の p は、2 つの層の食い違った組を合わせた McNemar の正確検定（両側）と同じ値になる**（層を分けても p は変わらない。`docs/stage4/test1_analysis.md` 3-2 で畳み込みと一致することを確かめた）。「層別」は、層ごとの b_s・c_s を表に並べることを指し、検定の値は合計の McNemar と同じと報告に書く。【固定。作者の答え 10/09: 問 2】
- 両側の p は、b＋c 回の二項で、観測より偏った側の確率の 2 倍（上限 1）とする。b＋c＝0 なら p＝1。
- **検定の族: H1・H2・H3 で Holm 補正**（α＝0.05）。H1 が無いとき（【P-1】）は H2・H3 の 2 つで Holm。【固定】
  - 手順: p を小さい順に p(1) ≤ p(2) ≤ p(3) と並べ、p(1) ≤ 0.05/3、p(2) ≤ 0.05/2、p(3) ≤ 0.05 を順に確かめる。満たさない所で止め、その後ろは全部「通らない」。補正後の p は、(m−i+1)×p(i) の累積の最大（上限 1）。
  - H2・H3 は、ほぼ確実に通る見込みである（段階 3 は 13 対 0、p＝0.00024。復帰デモなしのモデルは 33 中 32 で目標の上まで降りない）。H2・H3 の p がどちらも 0.025 以下（小さいほうは 0.0167 以下）なら、H1 は実際には α＝0.05 で検定される。この事実を結果の節に書く（critique #6）。【固定】

## 12. 掲示板 0157 の条件とテスト 1 の解析の対応

### 12-1 「改良版」の中身

0157 は「改良版」を定義していない。テスト 1 では、作者の D3 の答え（2026-10-09）により**案 B** とする。案 B は束 2 B2 で設定を採ったときだけ成り立つので、採らなかった枝（枝 2・枝 4）では案 A に決まる（規則。人の判断を入れない）。
