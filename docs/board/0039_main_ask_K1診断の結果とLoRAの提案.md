## 求めること（LoRA の分岐の承認。手順書 §6「対象の層と rank を提案し、承認を得てから」）

1. **LoRA の対象**（B_提案書 §11 の案から）
   - (a) SmolVLM2 のテキスト部の 16 層のうち **8〜15 の 8 層**の `q_proj`・`v_proj`、rank 16、alpha 32。行動エキスパートと射影層（`state_proj`・`action_in_proj`・`action_out_proj`・`action_time_mlp_in/out`）は `--peft.full_training_modules` に入れて全部学習する。`train_expert_only`・`freeze_vision_encoder` は true のまま
   - (b) 12〜15 の 4 層（ほかは (a) と同じ）
   - 推奨 (a)。指示が向きに全く効いていないので、言葉と画像を混ぜる層を広めに開ける。映像用メモリの見込みは 9〜10 GiB（上限 14）。50 手の試しで実測してから本番
2. **足す 2 つ**（0038）
   - 最初の 2 秒（frame_index 0〜19）のこまを 5 倍の重みで引く: `lerobot-train` は並べ方を `EpisodeAwareSampler` で作るので、それを重みつきの引き方に差し替える小さな起動用の包み（`recovla.policy`、LeRobot のファイルは書き換えない）で行う。起動器（`train_launcher`）に設定のキーを足す。重みの効き（最初の 2 秒のこまが引かれた割合）は学習の記録に残す
   - K1 の配置を 30 → 100（種 10000〜10099、空の箱・開始姿勢 home、300 本）。10000〜10029 は今と同じ配置になる
3. **手数**: 8000 手のまま（データが 3.3 倍になるので、1 本あたりに見る回数は減る）。または 12000 手。推奨は 8000 手（時間は 1.1〜1.3 時間の見込み）
4. **peft を入れる**: B_提案書 §3 の 7 と同じ方法（`uv pip install peft --constraint env\requirements-lock.txt`、ネットワークから）。入った版を lock に追記する

承認の後の順番（見込み）: peft を入れる → 重みつきの引き方と LoRA の設定を起動器に足す（単体検査つき）→ 配置 100 のデータを作って変換（15〜20 分）→ 50 手の試し（メモリと速さ）→ 8000 手（1.1〜1.3 時間）→ E6・閉ループ → 報告して止まる。学習中は、0036 の答えが来ていれば Step F の完了条件の試験の準備を進める（描画は学習と同時に回さない）。
