## 要点（3行以内）

8 組 × 120 回（選択用の帯 199000〜）を 18:10〜19:15 に回した。エラーなし。決まりにより**最終モデルは R2**（自然はどちらも 29/30、立ち直りの合計は R2 39/77・R1+ 21/74）。
主な検定の結果: E3 は本線・sync とも R1 が N1 を上回った（P1: 17/23 対 3/25、Holm 後 p = 0.002）。E4 は rtc で P1 が 0/22、naive で 17/23（p < 0.001）。E8 は R2 が R1+ を上回った（23/24 対 12/22、p = 0.012）。
E5 の主な指標（自然の接触の有無）は 3/30 対 4/30 で差がなかった。残った接触はどれも置く間際の箱の壁で、触れていたこまはフィルタで短くなった（9〜10 → 3）。予備評価を見た後の設計の変更は提案しない。

## 本文

### 1. 回したもの

- 8 組（0083 の 1）。各組は、自然 `natural:199000:10`（30 回）と P1 199100〜199129・P2 199200〜199229・P3 199300〜199329（各 30 回）
- A〜G は 18:10〜19:05、H は最終モデルが決まった後の 19:06〜19:15。同時 3 本で、全 32 本がエラーなし
- 実行の設定は試行の記録で確かめた。A・B・F・G は naive d=4＋フィルタ、C・D は sync＋フィルタ、E は rtc d=4（範囲 40・指数）＋フィルタ、H は R2 の naive d=4・フィルタ切
- 最終評価用の帯（110000〜189999）は使っていない（0084 で確認済み、今回も使っていない）

**読み取り**（予備評価なので結論は最終評価で出す）
- **E3 の本線で、R1 の復帰データの効きが出た**。G2 までの評価の設定（rtc 範囲 40）では R1 の P1 が 0/25 で N1 と差がなかった。本線を naive に決め直した後は、遅れ d=4 があっても R1 が N1 を上回る。「遅れそのものより RTC の寄せが P1 の立ち直りを止めていた」（0074・0075）と合う
- **E4 の取引が図で見える**（`docs/media/2026-09-27_EPRE/e4_tradeoff_pre.png`）。rtc は継ぎ目が最も滑らか（中央値 0.011 m/s 対 naive 0.044）だが、P1 は 0/22
- **E8**: R2 の区間（評価と同じ実行で方策が行き着いた状態からの引き継ぎ）が、P1・P3 で R1+ より効いた

**E5 の接触の中身**（自然）: フィルタありで残った 3 本は、どれも置く間際（9.5 s ごろ）の箱の壁（yn）で、触れていたこまは 3。フィルタなしの同じ種では 9・10・5 こまで、なしだけの 1 本は隣の立方体（緑）への接触と失敗（199006）だった。試行ごとの接触の有無では差が出ず、触れている時間が短くなっている。

### 5. 予備評価を見た後の変更

**提案しない**（0084 の 3 の決まりに従い、変えるなら諮る）。ただし気づいた点を 1 つ書く。
- E5 の主な指標（自然の接触の有無）は、フィルタで触れている時間が短くなっても変わらない。置く間際の短い接触が残るためで、予備評価では差が見えなかった。指標を「接触したこまの数」などに変えると予備評価を見た後の変更になるので、**変えないのが本線の案**。最終評価でも有無を主にし、こまの数は副の指標として示す
