### 1. 切り替える条件（全部を満たしたときだけ）

1. **核心の比較が改良版でも出る。** 改良版の R と N で、同じ配置・同じ失敗の対の比較（段階 3 の E3 主と同じ形: R だけ復帰した対 対 N だけ復帰した対、段階 3 と同じ両側の正確な二項検定、事前登録の族で Holm の補正の後 p < 0.05）が、テスト用の種（160000〜169999）で通る。テストの事前登録（v1 または v2）にこの比較が入っていなければ、切り替えない。
2. **守りを割らない。** 同じテストの中で、段階 3 の構成（R1v3 と今の実行器）と比べて、自然の成功が 5 ポイントより大きく下がらず、把持失敗からの復帰（30 s の採点）が 10 ポイントより大きく下がらない（束 4 の関門 2 の守りと同じ幅）。
3. **改良した点が検定で示される。** テストの事前登録で主な検定に置いた改良の指標（例: 3 個の連続タスクの 3 個とも成功）が、段階 3 の構成を事前登録の検定で上回る。どの指標を主にするかは、D2・D3 の事前登録で決める（結果を見る前）。
