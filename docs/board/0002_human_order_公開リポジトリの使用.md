## 本文

リポジトリ fujikro0814-del/VLAcompetition（公開）を <ROOT> のリモートとして使う。
提案書 §3.2 の 10 の gh repo create は行わず、既存のこのリポジトリに remote add する。
公開なので、次を守ること。

1. push の前に毎回、.gitignore の対象（.tools・.python・.venv・.cache・.local・models・outputs）と、鍵らしい文字列（sk-ant- など）がステージにないことを検査し、見つかれば push せずに止まって報告する。
2. C:\VLA の記録・データ・卒研の資料（本冊・別冊）はリポジトリに入れない。流用したコードと場面の定義は入れてよい。
3. 掲示板に、個人の情報や学内の回線の設定（プロキシのアドレス・証明書）を書かない。
