## 要点（3行以内）

振りの結果を見る前に、A・B の値の決め方を固める。A は「効かず」10% 以下の点が続く範囲、B は「着地が不自然」20% 以下の最小の下限。
B は、20% 以下の点がないか、「机上の他の立方体」が下限とともに増えているなら、値を決めずに ask を出す。種は n ≤ 200。

## 本文

チャット（2026-09-26）での監督の補足:

1. A: 上げる型の「注入が効かず」の割合は、分母を「n − 注入前の自然な失敗」にして出す。点の推定値が 10% 以下の点が続く範囲をつないで `raise_close_m` とし、`raise_ratio` は 0.5 のまま。条件を満たす点がなければ `raise_ratio` 0（横ずらしだけ）
2. B: 「着地が不自然」の割合（分母は 確定＋不自然）の点の推定値が 20% 以下になる、最小の下限を採る。Wilson の区間は添えるだけ。あわせて各点の除外（`r0_below_min`）の件数と、確定まで進んだ割合（確定数 / n）を表に入れる
3. 次のどちらかなら、B の値を決めずに ask を出す: (1) 20% 以下の点がない、(2) 内訳で「机上の他の立方体」の件が、下限を上げるにつれて増えている。その場合は、監督が次の案をまとめて出す: 0.15 m に戻す／壁の条件を緩める／落とす時点でほかの立方体からの距離を条件に足す
4. 種は n ≤ 200 に留める（それを超えると B と C の種の範囲が重なる）

## 本線の運用（書き写しに添える）

- 振りの各点は ±0.5 cm の幅を持つ（中心 2.0〜4.5 cm）。「続く範囲をつなぐ」は、条件を満たす隣り合った点の最小の中心 −0.5 cm 〜 最大の中心 +0.5 cm とする。条件を満たす連なりが 2 つ以上に分かれたら、長い方（同じ長さなら上げ幅の小さい方）を採り、報告に両方を書く
- 「確定」は注入の結果が confirmed のもの（成功＋立て直しに失敗）。B の「不自然」の分母は 確定＋着地が不自然
- 「増えている」は、下限の小さい順に並べた「机上の他の立方体」の件数が、最初の点より最後の点で多いこととし、各点の件数を表に並べて示す
- n は 120（B は 51200〜51319、C は 51400〜51519 で重ならない）
