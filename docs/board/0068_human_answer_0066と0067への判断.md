1. R2 の前に、原因の切り分けを回す（すべて選択用の帯の未使用の範囲から割り当て、種の台帳に記録する）

  (2) N1 で P2 誘発 30 回（G2 の P2 と同じ種 195000〜195029 で対にする）

  (4) G2 の P2 で成立した 40 回について、制御が戻った時点の状態（手と立方体の距離、グリッパの開き、手の高さ）の分布を、データの A・B・C の開始状態の分布と並べた図にする

2. R2 は乙で進める。ただし生成の前に計画を出して止まる。計画に入れるもの:
  - 甲（自然な走行での引き継ぎ）と、乙（学習用の配置で P1〜P3 を起こして引き継ぐ）の本数の配分。1 の結果（どの誘発で立ち直らないか）に基づいて決める

  - 台本が、手が離れてグリッパが閉じた状態から立て直せるかの生成の成功率（誘発の種類ごと）
  - 種は学習データ用の帯だけを使い、評価用の帯は使わない
  - R1+（R1 のデータだけで同じ手数を続けた対照）を手順書どおり作る
  - 以後の評価の P2 は「学習で見た形の失敗からの復帰」を測ることになる点を、報告の評価の節に明記する

  - N1 は復帰データを含まないので作り直さない、という前提が成り立つかの確認
  - 乙と並べて回す場合の日程への影響（10/19 の G3 までに収まるか）と、GPU の取り合いの順番
  - 丙をやった場合に E3 で何が言えるようになるか、やらない場合に何が言えないか
