**4 工夫した点（数字はテスト用 140000〜）**

1. 復帰デモの自動生成: 復帰デモありで学習したモデルとなしで学習したモデルを比べた。把持失敗の注入が両方で有効だった 27 対で、ありだけ回復 13・なしだけ 0（Holm 補正後 p = 0.0005）。同期実行でも 7 対 0（p = 0.016）→ 動画 1:00〜1:20
2. **センサの出力だけで動く実行系**（新）: 俯瞰・手首の RGB-D、関節の状態、グリッパの開き幅と、較正誤差を含む設置情報だけを使い、立方体の位置は画像から推定する。知覚の誤差は中央値約 11 mm・p95 約 28 mm（E10）。全 1,245 試行で、真値を使わない・世界を止めない・指令の上限を超えない（G1〜G3）の監査に違反 0 → 動画なし（本文のみ）
3. 推論遅延と RTC のトレードオフ: RTC は手先の加加速度を下げる（中央値 4.8 → 3.5）が、失敗注入なしの成功が 86% → 25%、接触が 10% → 47% と大きく下がったので、RTC を使わない非同期実行にした（チャンク境界での速度の不連続は今回の記録では測れていない）
4. 安全フィルタ: 知覚した障害物と箱の壁からの距離で指令を絞る。**数字の扱いは判断を求める（求めること 1）**。接触をなくす効果と成功の低下の副作用を両方書き、最終的な実行系では外したと明記する
5. 目標位置のキュー: 指示と目標位置のキューを一緒に差し替えると 99/99 が指示した色へ向かう。**キューだけを差し替えると 99/99 がキューの色へ向かい、指示文には 0/99 しか従わない**（方策は行き先をキューで決めている。正直に書く）
