### 3. Newcombe の照合: Table III の 4 例と照合済み

- **Table III の 4 例と照合済み。** (36, 12, 2, 0) → [0.0569, 0.3404]、(36, 14, 0, 0) → [0.1528, 0.4167]、(2, 98, 0, 0) → [0.9178, 0.9945]、(54, 0, 0, 0) → [−0.0664, 0.0664]。小数 4 桁で一致した（`test_newcombe10_matches_newcombe_1998_table_iii`）
  - 表の値は、監督が文献（Newcombe 1998, Statistics in Medicine 17:2635–2650）から引いて 0015 に書いたもの。この環境からは論文に接続できなかった（出版社・PubMed・論文の写しの置き場への接続が 403 で拒否された）
  - この 4 例は n00 = 0 で φ の補正が効かない。そこで補正の効く例として、(10, 0, 0, 10) → [−0.0898, 0.0898] を別に置いた。これは監督の独立な実装の値で、文献の値ではない。補正なしでは幅が 0 に潰れることも確かめた
  - φ の補正（`phi_correction=True`、分子が n/2 を超えれば n/2 を引き、0〜n/2 なら 0）は、0015 の 1 で方法 10 の定義として確定した
- あわせて、別の組み方の実装と照合した。Wilson の区間は、2 次方程式の根として求めた。φ は 0/1 の列の相関係数から求めた。差の区間は、幅を組み合わせる順を変えた式で書いた。照合した表は次の 933 通りで、差・下側の幅・上側の幅が一致した（幅は二乗で比べて 1e-12 以内）
  - 各セル 0〜4 のすべての表（624 通り）
  - 各セル 0〜59 の乱数の表 300 通り
  - 端の場合 9 通り
- あわせて次の性質も確かめた: 区間が差を含み [−1, 1] に収まる。a と b を入れ替えると区間は符号を変えて入れ替わる。α を小さくすると区間が広がる。φ = 0 なら 2 つの Wilson の幅の二乗和の平方根になる
- 独立な実装も同じ式から組んでいるので、式の読み違いはこの照合だけでは見つからない。これは上の Table III の照合で補った

### 4. 仕様（interfaces）で曖昧だった点と、どう解釈したか

結果が変わる点は 0014 に出し、0015 で決まった。

- Newcombe の φ の補正: 補正ありで確定した
- 巻き添えの「区間」: 仮の読み方で確定した。静止の判定は `success.rest_speed`
  - 玉突きは、区間に t_fire 以後の立方体どうしの接触（相手の色は問わない）があり、それが最初の contact_robot より先か同じこまなら「誘発による移動」に数える。0015 を受けて実装を改めた
- 復帰時間の「再び」: 仮の読み方で確定した。反応時間・復帰時間は、誘発が成立した試行だけで計算する
- 複数手順の段階別の到達: 仮のまま（複数手順は段階別の表に入れない）

それ以外に、次のように読んだ。

- a. `trial_metrics` の返り値: trial_record.md §6 には指標 18 個しかない。一方 results.md §2 は「列の名前は trial_metrics の返り値と同じ」としている。そこで trials.csv の全列（実験・条件・種・`t_success_s` などを含む）を、表と同じ並びで返すことにした
  - `d` は、sync なら 0、それ以外なら `runtime.delay_steps`
  - `target` は手順の目標を `>` でつなぐ。`induce` は種類がなければ `"none"`
  - `t_success_s` は、成功した試行の最後の手順の `t_success`。成功しなければ NaN
- b. 10 Hz の行動の列: `step % 50 == 0` のこま（2k）の `action` と `chunk_switch` を使う。旗が 2 こまのどちらに立っていても結果は同じ
  - v_k と v_{k−1} のどちらかが NaN の k は除く
  - 指示の切り替え（塊の作り直し）の時点も、行動が続いていれば継ぎ目として数える
- c. 手先速度の跳び: u_i = (ee_pos[i+1] − ee_pos[i]) / こまの間隔（こま i の後の区間の速さ）とし、切り替わりのこま i での |u_i − u_{i−1}| をとる。対象は b と同じ時点
- d. 反応時間: `t_failure` が格子の上にない場合は、d0 を「t_failure 以後の最初のこま」の距離とした。返す値は、見つかったこまの時刻 − `t_failure`（こまの時刻どうしの差ではない）
  - 目標は `t_fire` の時点のこまの `target` の色（−1 なら、その時刻を含む手順の目標）
  - 誘発が成立した試行（`established`）だけで計算し、それ以外は NaN
- e. 躍度: 試行の全体の x_des を使う（誘発の区間や、成功した後も含む）。差分に NaN があれば、その差分だけを除く。4 手に満たなければ NaN
- f. 誤り: こまごとの `target` と違う色を「目標でない」とした。複数の手順では、置き終えた立方体をまた持ち上げると誤りになる。手順の外（−1）のこまでは、全色を目標でないとした
- g. 接触回数: こま 0 の前は偽とする（こま 0 が真なら 1 回と数える）。対象の列は `wall_*` と、そのこまで目標でない `cube_*`
- h. 推論時間: `inference` のすべての項目の `wall_s` を使う。最初の 1 回も除かない（d を決めるときの `delay_rule` は最初を除くが、指標については決まりがない）。p95 は numpy の既定（線形補間）で求める
- i. `recovered`: 誘発が成立した試行で、json の `success` をそのまま使う。成立していなければ None
