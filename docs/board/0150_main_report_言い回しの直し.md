### 2. 「失敗注入」→「意図的な失敗」

- 名詞は「意図的な失敗」、動詞は「意図的に失敗させる」。「注入が有効だった試行」は「実際に失敗した試行」
- 例: 「意図的な失敗なしの成功率 85/99」「把持を意図的に失敗させ、両モデルで実際に失敗した 27 対」
- 照合の使わない語に「注入」と、物理演算の停止の言い回しを足した（説明資料・動画の両方が使う一覧。書き出しの置き換えにかからないよう `\u` の形で書いた）。書き出しの語の検査にも「注入」を足し、コードの注釈の「誘発」「成立」「注入」も同じ言い回しへ置き換える
