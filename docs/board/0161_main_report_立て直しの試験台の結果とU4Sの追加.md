### 2. 採点の逸脱（版 1.1、二次の分析）

- 見つかったこと: 失敗の述べ方（「終わりませんでした」「未完了」「入らず」など）を c1 の正規表現が拾えず、失敗した色を述べた報告が「言及なし＝正しくない」になっていた。箱の中の色の一部の言い方（「両方」「〜が箱の中です」）も取りこぼした。行番号に項目が入っておらず、同じ入力で真値の違う行が区別できなかった。
- 扱い: 版 1.0 の結果と U4S の判定は変えない（ビット単位で出し直せることを確かめた）。版 1.1 は別のファイル（score_s3_v11.json）に出し、手順書の第 11 節（逸脱）に書いた。

| モデル | 版 1.0（主） | 版 1.1（二次） |
|---|---|---|
| Haiku 5.5 | 27.5% | 52/80 = 65.0%（54.1〜74.6%） |

- 版 1.1 で規則を計算すると Sonnet − Haiku = +1.25 ポイントで、条件を満たさない（参考だけ。判定には使わない）。版 1.0 の差の大部分は、c1 の取りこぼしが Haiku の言い方に多かったことによる。U4S の結果を書くときは、このことを必ず添える。
