### 0046: K1 は「目標の位置を上位層から渡す」構成に切り替える。手順書の色の差・間隔・2 色の案は採らない

理由: VLA 単体では指示と画像を結びつけられない（学習データの上でも D2 51%）。大きな VLA でも指示が無視されやすいという既知の弱点に当たる。本題の復帰デモの比較（E3）は影響を受けない。

1. 目標の手がかり
   - 俯瞰画像から指示色の画素の重心を求め、机の面（立方体の中心の高さ）へ投影した x, y と、見えているかの旗を状態に足す（15 → 18 次元）
   - 投影にはカメラの較正の値（内部・外部）を使ってよい。Step I の色の判定と同じ部品・同じ閾値にする
   - 見えないとき（腕で隠れたとき）は最後に見えた値を保ち、旗を 0 にする。推論のたびに計算し直す（落下の後も追う）
   - 指示文は残す（LLM → 色 → 指示文と手がかりの両方）
2. ズルにしないための決まり
   - 手がかりは学習でも推論でも俯瞰画像からだけ計算する。シミュレータの真値を方策の入力に入れない（台本と成否の判定は真値のまま）
   - 色の判定の閾値は学習データの種（1 万台）だけで決めて設定に固定する。選択用・最終評価用の種では調整しない
3. 単体検査: K1 の 300 本の全こまで、手がかりと真値の差（中央値・95 百分位・最大）と見えない割合を、区間（接近・把持・運搬・配置）ごとに出す
4. K1 のやり直し: 配置 100 の 300 本の変換に手がかりを足す（生成し直しはしない）。行動エキスパートだけ（LoRA と 5 倍の重みは外す）、8000 手
5. 判定（前回と同じ種）
   - 閉ループ 30 回（191000〜191029）で、持ち上げが半数以上、違う色が 10% 以下
   - E6 は指示と手がかりを一緒に差し替えて行い、正答率 90% 以上
   - 参考: 手がかりだけを差し替え、指示はそのままにした E6 も測る（方策が何に従っているかを見る）
   - 閉ループの失敗は段階ごと（接近・把持・運搬・配置）に分けて出す
   - 合格したら報告して止まる（R1・N1 への手がかりの追加と Step H は、承認の後）
   - 不合格なら報告して止まる（次の手の候補: 俯瞰カメラを寄せて立方体を大きく写す）
6. 文書: 構成の変更（LLM → 色 → 色の判定 → 位置 → VLA）と理由を docs に記録する。報告用に、K1 の不合格（VLA 単体、E6 31%、D1・D2・LoRA の枝）の結果はそのまま残す。最終評価の E6 の定義が変わることを、計画の差分として書く
