## 要点（3行以内）

評価は 2 段にする。選択用の帯（199000〜）で縮めた**予備評価**（1 組 120 回 × 8 組、約 1.2 時間）を回してから、Step J で最終評価用の帯（110000〜）を使って**同じ設計の最終評価**（1 組 249 回 × 8 組、約 2.5 時間）を回す。
8 組は、本線の R1・N1・R2・R1+、sync の R1・N1、rtc の R1、フィルタ切の最終モデル。E の間で共有する（例: E3 の本線の R1 ＝ E4 の naive の R1、E3 の sync の R1 ＝ E4 の sync）。
検定は、同じ種の対の正確な McNemar 検定を主とし、E ごとに主な検定を 1 つ（E3 は 2 つ）前もって決める。E1・E2・E5 の「最終モデル」（R2 か R1+）の決め方も諮る。

### 4. 各 E で示すものと検定（計画書 §4.6 と 0063 の 5 に沿う）

**検定の方法（全 E 共通）**
- 成否（自然）: 同じ種・同じ目標の対で、**正確な McNemar 検定**（両側）と、対応のある割合の差の 95% 区間（Newcombe の方法）
- 立ち直り（P1〜P3）: **両方の条件で誘発が成立した種の対だけ**で McNemar 検定。成立率は条件ごとに併記する。誘発の種類ごとの数と、P1〜P3 を合わせた数の両方を出す
- 連続量（継ぎ目の跳び、躍度、反応時間）: 種ごとの値の対で Wilcoxon の符号順位検定
- **主な検定は E ごとに前もって決める**（下の表）。それ以外は記述として出し、p 値は参考とする。E3 だけは主な検定が 2 つなので Holm で補正する

| E | 比べるもの（組） | 主な検定（前もって決める） | 併せて示すもの |
|---|---|---|---|
| E1 | 最終モデルの自然（F か G） | —（1 条件） | 成功率（Wilson 区間）、誤り率、巻き添え率、段階別の到達、接触率 |
| E2 | 最終モデルの P1〜P3（F か G） | —（1 条件） | 成立率、復帰率（種類ごと）、反応時間、復帰までの時間。**P1 の反応時間には (5) の注記**（R2 の P1 は、評価で制御が戻る「閉じた直後の低い姿勢」をほとんど覆っていない＝0078・0079） |
| E3 | R1 と N1、本線（A・B）と sync（C・D） | ① 本線の立ち直り（P1〜P3 合わせた成立の対）の McNemar、② sync の同じもの。Holm で補正 | 自然の成功、種類ごとの立ち直り。本線と sync の差（遅れで効きが消えるか）を並べる |
| E4 | sync（C）・naive d=4（A）・rtc d=4（E）、どれも R1・フィルタあり | ① naive と rtc の継ぎ目の跳び（Wilcoxon）、② naive と rtc の立ち直り（McNemar）。取引を示すための 2 本で、補正はしない（向きが逆の主張のため） | sync との比較、躍度、反応時間、自然の成功。**(4) 自然な試行の失敗の形の内訳を条件ごとに**（0069 の 5＋0070 の 5 の検出器で、掴み損ね・机の上の落下・その他の落下・誤った色・停滞・時間切れ）。**図**: 横に継ぎ目の跳び（中央値と区間）、縦に立ち直りの率（区間）を条件ごとに 1 点ずつ置き、取引を一目で示す |
| E5 | 最終モデルのフィルタあり（F か G）となし（H） | 自然の接触（試行の有無）の McNemar | 自然の成功、**(2) P1〜P3 の立ち直り**（種類ごと）、接触回数、巻き添え率、フィルタが働いたこまの割合。194028 の形（隣の立方体への接近を止め続けた失敗）を試行ごとに数えて示す |
| E8 | R2（F）と R1+（G） | 立ち直り（P1〜P3 合わせた成立の対）の McNemar | 自然の成功、種類ごとの立ち直り、反応時間。**「学習で見た形の失敗（同じ誘発で作った状態）からの復帰」を測っていて、範囲の外への汎化は測っていない**と書く（0069） |

- 継ぎ目の跳びは、方策の出した行動（塊の切り替わりでの速度の差）で測るので、フィルタの影響を受けない。躍度は参照位置（x_des）で測るので、フィルタが働いた分を含む。どちらかを書き添える

### 5. 最終モデルの決め方（予備評価で決める。決まりは予備評価を回す前に commit する）

E1・E2・E5 は「最終モデル」で回す。候補は R2 と R1+（どちらも R1 から同じ手数だけ続けたもの）。
- (a) 予備評価の自然の成功数が、よい方から 3 回以内（30 回中）の候補だけを残す
- (b) 残った候補のうち、P1〜P3 の立ち直りの合計（成立した試行が分母）が多い方。差が 3 以内なら同じとみなす
- (c) 同じなら **R2**（2 周目を発動した目的が復帰であり、作品の本線として予定していたため）

決めた最終モデルは、以後の結果によらず変えない。最終評価の組 H（フィルタ切）はこのモデルで回す。
