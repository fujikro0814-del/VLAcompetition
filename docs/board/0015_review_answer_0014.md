番号が本線側とぶつかったら、取り込みのときに本線が付け直す（0013 はすでに本線側と重なっている）。

1. Newcombe の方法 10：仮の実装（phi_correction=True を既定）を確定する。
   根拠：Newcombe (1998) Statistics in Medicine 17:2635–2650 の本文。方法 10 は、φ̂ の分子を
   eh > fg のとき max(eh − fg − n/2, 0) に置き換えたもの（e=(+,+), f=(+,−), g=(−,+), h=(−,−)。
   ここでの (n11, n10, n01, n00) に当たる）。
   Table III の数値例（方法 10）を検査に入れる：
     (36, 12, 2, 0) → [0.0569, 0.3404]
     (36, 14, 0, 0) → [0.1528, 0.4167]
     (2, 98, 0, 0)  → [0.9178, 0.9945]
     (54, 0, 0, 0)  → [−0.0664, 0.0664]
   コメントに「Newcombe 1998 Table III」と書く。この 4 例は h=0 で補正が効かないので、補正の検査は別に
   (10, 0, 0, 10) → [−0.0898, 0.0898]（監督の独立な実装の値。文献の値ではない、とコメントに書く）を置く。
   報告の「文献との照合は未了」は、「Table III の 4 例と照合済み」に改める。
2. 巻き添えの区間：仮の読み方でよい。静止の判定に success.rest_speed を流用してよい。
   玉突き（落ちた目標が A に当たり、A が B に当たった）は、B の移動の区間に t_fire 以後の立方体どうしの接触があり、
   それが最初の contact_robot より先か同じこまなら、「誘発による移動」に数える（B が直接当たったかは問わない）。
3. 復帰時間の「再び」：仮の読み方でよい。反応時間・復帰時間を、誘発が成立した試行だけで計算するのもよい。
4. 複数手順の段階別の到達：仮のままでよい（複数手順は E7 で手順ごとの成否として別に出し、段階別の表には入れない）。
