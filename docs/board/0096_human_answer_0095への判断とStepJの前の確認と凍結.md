### 1. Step J の前の確認（一行ずつ）

- **(1)** 戻す動きは `src/recovla/planner/executor.py`（`ReturnMotion`・`TaskExecutor._return_to_retreat`）だけにあり、呼ぶのは `scripts/51_planner.py run` だけ。E1〜E5・E8 の `41_results.py`（→ `eval/closed_loop`・`eval/scene_trial`）と E6 の `20_k1.py e6` は `recovla.planner` を import しない。これを `tests/test_i_planner.py::test_return_motion_is_only_in_the_task_executor` で確かめる（409 件すべて通過）

### 2. 報告のための集計（0095 の検証の値も出し直した）

- **開いたときに挟んでいた立方体**（`51_planner.py` の `dropped_on_open`。戻す動きの始めに指を開いたとき、指先の中心から 3.5 cm 以内で最も近い立方体。落ちた先は戻す動きの終わりの位置で、箱の中・別の立方体の上・机・その他に分ける）
