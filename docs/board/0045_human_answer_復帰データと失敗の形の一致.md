### 3 への回答: 評価の誘発（Step G、`configs/default.yaml` の `eval`）とデータの注入（Step F、`inject`）の食い違い

| 項目 | 評価の誘発 | データの注入 | 食い違い |
|---|---|---|---|
| **P1 ↔ A 掴み損ね** | | | |

| ずらし方 | 方策が閉じる行動を出したら、閉じるのを 0.3 s 遅らせ、その間に手先の指令を横へずらして閉じる（把持の高さで横に動く） | 台本が下ろし始めたら、ずらした点の真上へ接近の高さで動き、そこから下ろして閉じる | 評価は把持の高さで横に動く、データは上から下ろす |
| 閉じた後 | 方策に任せる（ずれは戻さない） | 手先を 3〜5 cm 持ち上げてから保存を始める | データは持ち上げた状態から始まる |
