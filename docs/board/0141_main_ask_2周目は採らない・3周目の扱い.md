## 求めること

決裁へ。3 周目をどう使うか。

1. **3 周目は回さず、R1v3・N1v3 で最後の段に進む**（安全フィルタの確定の判定 → 最終評価）。日程に最も余裕がある。1 周目の検証の差（R だけ復帰 25 対 N だけ 0、2 周目の種でも 35 対 0）が、E3 の主な根拠になる
2. **3 周目に、R にだけ効く改善を入れる**（目標書 v3 の範囲で、R と N に同じだけ当てるもの。例: 両方のデータの本数を増やし、R には復帰 A・B・C も同じ割合で増やす）。R の P1 の復帰の割合を上げる狙い。案は諮ってから回す（作り直しと学習で約 1 日、10/15 の期限には間に合う）
3. **3 周目に、学習の設定（ステップ数・画像の拡張）を R・N 同じに変える**。2 万と 3 万手で差がない（0124）ので、効く見込みは低い

本線の推奨: **1**。理由は、(i) R1v3 で E3 の差はすでに大きく、2 周目の種でも再現した（35 対 0）、(ii) 3 周目の改善を R と N に同じだけ当てる制約のもとで、R だけを上げる手は「復帰データの割合を増やす」くらいしかなく、効く根拠が弱い、(iii) 最終評価までの残りの手順（フィルタの確定の判定・最後の選択・最終評価）に余裕を残せる。
